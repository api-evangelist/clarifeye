# Clarifeye

- [Submit a signal](https://docs.clarifeye.ai/api-reference/signals/submit-a-signal.md): Submit a signal about the project's content: the signal text itself, plus optional `context.additional_details` with extra context for the reviewer. The signal shows up in the review UI for domain experts.
- [Update signal status](https://docs.clarifeye.ai/api-reference/signals/update-signal-status.md): Mark a signal as reviewed or update other fields.

- [Run a tool](https://docs.clarifeye.ai/api-reference/tools/run-a-tool.md): Execute a configured tool with provided parameters.
